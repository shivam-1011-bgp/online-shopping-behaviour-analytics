# Online Shopping Behaviour Analytics System

## About the Project
The Online Shopping Behaviour Analytics System analyses customer shopping activities using SQL and NoSQL databases. It helps identify sales trends, popular products, customer preferences, and cart abandonment.

## Technologies Used
- **MySQL:** Stores customers, products, and order details.
- **MongoDB:** Stores browsing and shopping activity events.
- **Python:** Performs data processing and analysis.
- **Streamlit:** Creates an interactive analytics dashboard.
- **Plotly:** Displays charts and visualisations.

## Key Features
- Customer and product data management
- Sales and revenue analysis
- Popular product and category analysis
- Shopping cart activity analysis
- Interactive dashboard

## Project Structure
- `app.py` — Dashboard application
- `requirements.txt` — Python dependencies
- `database/` — MySQL scripts
- `mongodb/` — MongoDB sample events
- `src/` — Analytics functions
- `docs/` — Project report
